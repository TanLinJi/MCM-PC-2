# Legacy Experiments Before MCM-PC Restart

This directory archives early exploratory experiments conducted before the formal MCM-PC experiment numbering reset.

These experiments include early text prototype enhancement, entropy/margin reliability, global-local consistency, and conservative negative cache attempts. They were useful for understanding failure modes, but they are no longer part of the formal experiment sequence.

Formal experiment numbering after the reset:

- E0: Point-Cache baseline reproduction and baseline result analysis.
- E1: Text Prototype Enhancement with point-cloud-aware and dynamically generated prompts.
- E2: Reliability-Gated Local Cache.
- E3: Conflict-Aware Negative Suppression.
- E4: Reliability-Aware Multi-Cache Matrix.
- E5: Ablation studies and visualization.

Archived legacy experiments must not occupy or affect the new experiment numbering.
