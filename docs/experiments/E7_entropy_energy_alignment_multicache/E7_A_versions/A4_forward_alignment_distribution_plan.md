# E7-A4 临时计划：前置高可信对齐分布

日期：2026-06-12  
状态：临时计划，待 E7-A3 对齐缓存样本正确率诊断后决定是否实现

---

## 1. 背景

用户提出一个更本质的方向：

```text
在进入缓存或进入分布之前，先筛掉不可靠样本。
```

这比门控（gating）更本质。门控主要控制最终得分融合，而前置筛选会直接影响缓存库和分布本身的干净程度。

---

## 2. 核心假设

E7-A4 的核心前提是：

```text
历史上实际进入或替换过对齐缓存的样本，其 zero-shot 伪标签准确率足够高。
```

只有这个前提成立，才能把这些样本作为高可信样本来更新前置对齐分布（forward alignment distribution）。

该前提由 E7-A3 诊断实验验证。E7-A3 使用真实标签（ground-truth labels）只做离线统计，不参与测试时适应（Test-Time Adaptation, TTA）的缓存更新或最终预测。

---

## 3. 计划方法

当前 E7-A0/A1/A2/A3 的顺序是：

```text
熵缓存更新 || 能量缓存更新
        -> 如果同一样本同时进入二者，再更新对齐缓存
```

A4 计划改成：

```text
当前样本 x
-> 计算零样本 logits、熵（entropy）、能量（energy）
-> 如果 entropy 低 且 energy 低，且符合高可信对齐分布：
       更新前置对齐分布（forward alignment distribution）
-> 再执行熵缓存和能量缓存的并行更新
-> 熵缓存和能量缓存的替换逻辑参考前置对齐分布
```

也就是说，对齐模块不再是后置缓存，而是更早建立的高可信分布。

---

## 4. 与缓存的关系

A4 不应简单删除缓存。分布和缓存的作用不同：

| 组件 | 优点 | 缺点 |
|---|---|---|
| 只用分布 | 稳定、抗单个样本噪声 | 容易抹平类别内多模态结构 |
| 只用缓存 | 保留实例级局部结构，适合近邻投票 | 容易被错误伪标签污染，容量小则不稳定 |
| 分布 + 缓存 | 分布负责筛选和替换，缓存负责实例级投票 | 需要设计好二者的耦合方式 |

A4 的目标不是删除缓存，而是让分布先负责“可信区域”的建模，再让缓存围绕这个可信分布维护实例。

---

## 5. 可能的参数

具体阈值待 A3 后决定，候选参数如下：

| 参数 | 含义 |
|---|---|
| `E7_A4_ENTROPY_MAX` | 低熵样本最大熵阈值 |
| `E7_A4_ENERGY_MAX` | 低能量样本最大能量阈值 |
| `E7_A4_ALIGN_MIN_COUNT` | 前置对齐分布最小可用样本数 |
| `E7_A4_ALIGN_WEIGHT` | 前置对齐分布参与替换打分的权重 |

阈值不能使用 clean/corruption 标签或真实标签设定。可以用在线统计，例如熵分位数、能量分位数、running z-score 等。

---

## 6. 暂停原因

暂不立刻实现 A4，原因是：

1. 需要先确认进入对齐缓存样本的 zero-shot 伪标签累计正确率是否足够高。
2. 需要先看该正确率是否在不同 corruption 上稳定，而不是只由少数场景支撑。
3. A4 会改变缓存更新顺序，属于更大的结构变动，应该建立在更明确的诊断证据上。

---

## 7. 后续触发条件

如果 A3 结果显示：

```text
all_alignment_entered_zs_acc 明显高于整体 zero-shot 准确率；
entered 样本数量足够；
该现象在多个 corruption 上稳定；
```

则可以启动 A4。
