# E1-S1：manual_full_llm_fusion 融合权重消融实验分析

更新日期：2026-06-03

## 1. 实验目的

E1 smoke test 已经证明，原始完整手工模板与 LLM 生成类别描述进行文本原型融合，可以超过原始 zero-shot baseline。

在 smoke test 中，默认融合权重为：

| 分支 | 权重 |
|---|---:|
| manual_full | 0.75 |
| LLM | 0.25 |

该设置取得了 48.88 的平均准确率，相比 baseline zero-shot 的 47.68 提升 1.20。

但是，0.75:0.25 不一定是最优融合比例。由于前序实验显示 `llm_only` 明显低于 `manual_full`，说明 LLM 生成描述不适合替代原始手工模板，只适合作为补充语义分支。因此，本实验进一步进行融合权重消融，分析不同 LLM 引入比例对最终分类性能的影响。

## 2. 实验设置

| 项目 | 设置 |
|---|---|
| 阶段 | E1-S1 |
| 实验类型 | 融合权重消融 |
| Backbone | ULIP |
| 数据集 | ModelNet-C |
| 损坏强度 | severity=2 |
| 损坏类型数量 | 7 |
| 任务设置 | zero-shot |
| 融合方法 | manual_full_llm_fusion |
| LLM 描述数量 | 每类 10 条 |
| LLM prompt 来源 | shared_prompts，共享缓存 |
| 是否重新生成 LLM prompt | 否 |

共享 LLM prompt 缓存路径：

    Point-Cache/results/E1_text_prototype_enhancement/shared_prompts/modelnet_c_deepseek_deepseek-v4-pro_multiview_2d3d_10_prompts.json

该缓存由 E1 smoke test 中已生成的 LLM 描述复制而来。所有权重消融实验均读取同一份缓存，从而保证不同权重之间只比较融合比例，不引入 LLM 生成随机性的影响。

## 3. 消融设定

本次共测试四组融合权重：

| 实验编号 | 方法 | manual_full 权重 | LLM 权重 | 说明 |
|---|---|---:|---:|---|
| 01_1 | manual_full_llm_fusion | 0.90 | 0.10 | 非常保守地引入 LLM 描述 |
| 01_2 | manual_full_llm_fusion | 0.85 | 0.15 | 中等保守地引入 LLM 描述 |
| 01_3 | manual_full_llm_fusion | 0.75 | 0.25 | smoke test 中取得正结果的默认权重 |
| 01_4 | manual_full_llm_fusion | 0.50 | 0.50 | 较高 LLM 权重，用于观察是否发生文本原型偏移 |

对比 baseline 为：

| 方法 | 说明 |
|---|---|
| baseline zero-shot | manual_full，即 Point-Cache 原始完整手工模板 |

## 4. 总体结果对比

| 方法 | manual_full:LLM | 平均准确率 | 相对 baseline zero-shot |
|---|---:|---:|---:|
| baseline zero-shot | 1.00:0.00 | 47.68 | 0.00 |
| manual_full_llm_fusion | 0.90:0.10 | 48.41 | +0.73 |
| manual_full_llm_fusion | 0.85:0.15 | 48.62 | +0.94 |
| manual_full_llm_fusion | 0.75:0.25 | 48.88 | +1.20 |
| manual_full_llm_fusion | 0.50:0.50 | 48.37 | +0.69 |

总体结果表明，四种融合权重全部超过 baseline zero-shot。这说明 LLM 生成类别描述作为补充语义分支具有稳定有效性，并不是单一权重下的偶然结果。

其中，0.75:0.25 的平均准确率最高，达到 48.88，相比 baseline 提升 1.20。0.85:0.15 的平均准确率为 48.62，相比 baseline 提升 0.94，虽然略低于 0.75:0.25，但整体更稳健。0.50:0.50 虽然仍超过 baseline，但平均准确率低于 0.75:0.25 和 0.85:0.15，说明 LLM 权重过高可能削弱 manual_full 的稳定语义锚定作用。

## 5. 分损坏类型结果对比

| 损坏类型 | baseline zero-shot | 0.90:0.10 | 0.85:0.15 | 0.75:0.25 | 0.50:0.50 |
|---|---:|---:|---:|---:|---:|
| add_global | 34.00 | 34.08 | 33.95 | 33.55 | 30.63 |
| add_local | 43.92 | 44.33 | 44.61 | 44.61 | 42.06 |
| dropout_global | 54.70 | 55.83 | 56.44 | 57.01 | 58.59 |
| dropout_local | 50.57 | 52.27 | 52.88 | 53.44 | 53.69 |
| rotate | 55.19 | 55.96 | 56.12 | 56.36 | 57.09 |
| scale | 50.89 | 51.66 | 51.78 | 52.76 | 53.85 |
| jitter | 44.49 | 44.73 | 44.57 | 44.45 | 42.67 |
| 平均 | 47.68 | 48.41 | 48.62 | 48.88 | 48.37 |

## 6. 相对 baseline 的提升分析

| 损坏类型 | 0.90:0.10 | 0.85:0.15 | 0.75:0.25 | 0.50:0.50 |
|---|---:|---:|---:|---:|
| add_global | +0.08 | -0.05 | -0.45 | -3.37 |
| add_local | +0.41 | +0.69 | +0.69 | -1.86 |
| dropout_global | +1.13 | +1.74 | +2.31 | +3.89 |
| dropout_local | +1.70 | +2.31 | +2.87 | +3.12 |
| rotate | +0.77 | +0.93 | +1.17 | +1.90 |
| scale | +0.77 | +0.89 | +1.87 | +2.96 |
| jitter | +0.24 | +0.08 | -0.04 | -1.82 |
| 平均 | +0.73 | +0.94 | +1.20 | +0.69 |

可以观察到，不同权重在不同损坏类型上呈现出明显差异。

0.90:0.10 是最稳健的设置，7 个损坏类型全部高于 baseline。虽然平均提升不是最高，但没有出现任何损坏类型下降。

0.85:0.15 在 6 个损坏类型上超过 baseline，仅 add_global 略低 0.05，几乎可以视为持平。该设置在稳定性和提升幅度之间取得了较好的平衡。

0.75:0.25 的平均准确率最高，在 dropout_global、dropout_local、rotate 和 scale 上提升明显，但 add_global 和 jitter 略低于 baseline。

0.50:0.50 表现出更强的两极化趋势。它在 dropout_global、dropout_local、rotate 和 scale 上表现最好，但在 add_global、add_local 和 jitter 上明显下降。特别是 add_global 从 34.00 降至 30.63，说明 LLM 权重过高时可能引入文本原型偏移，削弱原始手工模板的稳定语义锚点。

## 7. 各权重设定分析

### 7.1 0.90:0.10

该设置最保守，只向 manual_full 文本原型中加入 10% 的 LLM 描述分支。

结果：

| 指标 | 数值 |
|---|---:|
| 平均准确率 | 48.41 |
| 相对 baseline | +0.73 |
| 高于 baseline 的损坏类型数量 | 7/7 |

该权重说明，即使只引入少量 LLM 描述，也能够稳定提高分类准确率。这证明 LLM 生成描述确实提供了有效补充信息。

### 7.2 0.85:0.15

该设置在保留 manual_full 主导地位的同时，适度增加 LLM 语义分支。

结果：

| 指标 | 数值 |
|---|---:|
| 平均准确率 | 48.62 |
| 相对 baseline | +0.94 |
| 高于 baseline 的损坏类型数量 | 6/7 |

该权重相较 0.90:0.10 平均结果更高，同时仍保持较好稳定性。add_global 仅下降 0.05，几乎可以认为与 baseline 持平。因此，0.85:0.15 是一个稳健候选权重。

### 7.3 0.75:0.25

该设置是 smoke test 中已经取得正结果的默认权重。

结果：

| 指标 | 数值 |
|---|---:|
| 平均准确率 | 48.88 |
| 相对 baseline | +1.20 |
| 高于 baseline 的损坏类型数量 | 5/7 |

该权重取得当前最高平均准确率。它在 dropout_global、dropout_local、rotate 和 scale 等损坏类型上提升明显，说明 LLM 生成描述对结构缺失、旋转和尺度变化等情况具有一定补充作用。

不过，该权重在 add_global 和 jitter 上略低于 baseline，表明继续增加 LLM 权重可能会在噪声类损坏上带来不稳定性。

### 7.4 0.50:0.50

该设置将 manual_full 和 LLM 描述置于相同权重。

结果：

| 指标 | 数值 |
|---|---:|
| 平均准确率 | 48.37 |
| 相对 baseline | +0.69 |
| 高于 baseline 的损坏类型数量 | 4/7 |

该权重虽然平均结果仍高于 baseline，但已经低于 0.75:0.25、0.85:0.15 和 0.90:0.10。

其表现说明，LLM 分支权重过高会削弱 manual_full 的稳定语义锚定作用。尤其是在 add_global、add_local 和 jitter 上，性能下降明显。这进一步支持了 E1 的核心判断：LLM 描述应作为补充，而不是替代或主导。

## 8. 与 E1 smoke test 的关系

E1 smoke test 已经得到如下结论：

| 方法 | 平均准确率 |
|---|---:|
| manual_full | 47.68 |
| manual_3d | 35.63 |
| llm_only | 39.30 |
| manual_full_llm_fusion 0.75:0.25 | 48.88 |

本次权重消融进一步说明：

- manual_full_llm_fusion 在多个融合权重下均优于 manual_full；
- LLM 描述作为补充语义分支具有稳定价值；
- LLM 权重不是越大越好；
- manual_full 仍然应作为主导文本原型；
- 0.75:0.25 取得当前最高平均结果；
- 0.85:0.15 是更稳健的候选设置；
- 0.50:0.50 证明 LLM 权重过高可能导致文本原型偏移。

## 9. 当前结论

本次 E1-S1 融合权重消融得出以下结论：

1. 所有融合权重均超过 baseline zero-shot，说明 LLM 描述作为补充分支具有稳定有效性；
2. 0.75:0.25 取得最高平均准确率，是当前最优平均性能设置；
3. 0.85:0.15 接近最优且更稳健，可作为后续完整验证的候选权重；
4. 0.50:0.50 虽然仍高于 baseline，但在多个噪声类损坏上下降，说明 LLM 权重过高会削弱 manual_full 的语义锚点；
5. 后续 all35 完整验证建议优先比较 0.75:0.25 和 0.85:0.15。

## 10. 后续建议

下一步不建议继续在 severity=2 上增加更多权重组合。当前权重消融已经足够说明趋势。

建议进入 ModelNet-C all35 zero-shot 完整验证，优先测试：

| 权重 | 目的 |
|---|---|
| 0.75:0.25 | 当前平均最优 |
| 0.85:0.15 | 更稳健的候选权重 |

如果 all35 中 0.75:0.25 仍然最好，则将其作为 E1 默认融合权重。如果 all35 中 0.85:0.15 更稳定，则可以考虑将 0.85:0.15 作为正式权重。
