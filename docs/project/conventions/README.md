# Project Conventions Archive

本目录存放 MCM-PC-2 的长期协作规范、用户偏好、路径命名、实验记录规范和 Git 工作流约定。

## 当前主文件

| 文件 | 用途 |
|---|---|
| `user_preferences_workflow_conventions.md` | 用户偏好、协作规则、实验推进原则、脚本命名、文档要求、常见 bug 处理和当前研究判断 |

## 维护规则

- 当用户提出新的偏好、文档风格、实验命名规则、脚本规范、Git 规则或结果分析要求时，应同步更新本目录。
- 当项目进入新实验阶段，或已有规则与当前实践不一致时，应把规则修正到最新状态，避免后续接手者继续依赖过期上下文。
- 本目录记录“如何协作和推进项目”，不替代具体实验分析；具体实验结论放在 `docs/experiments/`。
- 如果主文件过长，按主题拆分，例如 `communication_preferences.md`、`experiment_workflow.md`、`documentation_rules.md`、`bug_handling_rules.md`，并在本 README 中更新索引。
- 更新后应及时更新 qmd 索引，保证后续检索能找到最新项目上下文。
