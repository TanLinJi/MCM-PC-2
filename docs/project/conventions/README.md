# Project Conventions

This directory stores collaboration rules, experiment workflow conventions, and
user preferences for the current DPC-Point project.

## Current File

| File | Purpose |
|---|---|
| `user_preferences_workflow_conventions.md` | Current user preferences, documentation rules, experiment workflow, naming conventions, and DPC-Point research judgment |

## Maintenance Rules

- Update this directory when the user changes a preference, naming rule, documentation style, experiment policy, or Git workflow rule.
- Keep concrete experiment conclusions under `docs/experiments/`.
- Keep paper positioning under `docs/proposals/` and `docs/paper/`.
- Archived MCM-PC/CANC conventions live under `docs/archive/legacy_mcmpc_canc/project/` and should not be used as current rules.
