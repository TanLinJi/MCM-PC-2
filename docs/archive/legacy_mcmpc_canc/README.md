# Legacy MCM-PC / CANC Archive

This directory preserves the previous research line before the project was
renamed and refocused as:

**DPC-Point: Distribution-Guided Prototype Cache for Robust Point Cloud Test-Time Adaptation**

The archived material is kept for traceability only. It should not be treated as
the current paper scope or experiment plan.
